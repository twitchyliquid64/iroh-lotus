# Vendored assets

`htmx.min.js` is htmx 4.0.0, unmodified, from
<https://cdn.jsdelivr.net/npm/htmx.org@4.0.0/dist/htmx.min.js>. htmx is
released under the Zero-Clause BSD license (<https://github.com/bigskysoftware/htmx>).

The server embeds it at build time so the UI works with no network beyond
the browser and the daemon's host.
